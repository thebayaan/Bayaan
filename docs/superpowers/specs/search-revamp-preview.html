Search v2 - Live Preview

Each query renders the actual orchestrator output (from the Jest snapshots), wrapped in the real React Native styles of TabBar, RankedResultRow, and SignalIcon. Tap a query chip to switch.

Heads up: in production the iOS native search-bar covers the top of the screen via Stack.SearchBar; here we render a mock field instead. The fixture has 3 test reciters (Mishary Alafasy, Sudais, Yasser Ad-Dossari); a real device will show the full reciter list returned by getAllReciters().
Tab colors and pill shape match TabBar.tsx. Row layout, font sizes, and signal icon match RankedResultRow.tsx + SignalIcon.tsx. Tier pill (right side) shows features.tier for clarity in the preview, the real app does not render it. Signal icons fire when personal/contextual boosts are present, with no history they stay off.
