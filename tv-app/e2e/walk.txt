# End-to-end walk through the TV app, shared by the Apple TV and Android TV
# screenshot runs, from a fresh install. Each line is:
#   <screenshot-name> <seconds-to-wait> <keys...>
# The keys are pressed in order (the runner waits 1 s after each), then the
# runner waits the given seconds and saves a screenshot.
# Keys: up down left right select back playpause hold relaunch none text:<word>
# A key may carry a repeat count: "up*7" is seven Ups (arrows, select, back,
# playpause). "hold" is a long press of OK, which opens a surah's, reciter's
# or playlist's menu. Run DRY_RUN=1 bash e2e/run-walk.sh android (or tvos) to
# check this file.
#
# Staying in sync on both focus engines:
# - Sidebar order: Home, Search, Surahs, Reciters, Adhkar, Library, Settings,
#   then the now-playing tile under Settings while something is queued (or a
#   relaunch's Continue). Up is trapped at Home and Down at the last item, so
#   "up*7 down*N select" from any place item opens place N (Home is 0), and
#   from the tile "up*8" reaches Home.
# - Back on a root place is stepwise: from the content it focuses that
#   place's own sidebar item; from another place's sidebar it goes Home onto
#   Home's sidebar item; from a place jumped to from content (an empty
#   playlist's Browse surahs) it goes back where the jump came from; on
#   Home's sidebar it leaves the app. So each section starts from a known
#   focus: "back up*7 down*N select" from a place's content, or "up*7 down*N
#   select" when focus is already on a sidebar item. The walk never presses
#   Back on Home's sidebar, and never starts a section with Back while a
#   stacked screen (player, reciter page, playlist, reader) is showing.
# - Back from the player or any stacked screen lands on the tile, row or
#   button that opened it, with the sidebar closed, on both engines.
# - The player's tray drops after 8 s idle without a panel, so tray steps wait
#   2-3 s. Closing a panel puts focus back on its tool.
# - The relaunch steps are the only other anchors: after a relaunch Home
#   focuses the hero's first button and nothing is queued.
# - Nothing is ever deleted: Settings' clear rows are pressed once each (and
#   the next press comes after the 5 s arm has run out), and a playlist's
#   Delete only once.
