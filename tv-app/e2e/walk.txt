# End-to-end walk through the TV app, shared by the Apple TV and Android TV
# screenshot runs. Each line is: <screenshot-name> <seconds-to-wait> <keys...>
# The keys are pressed in order, the runner waits, then saves a screenshot.
# Keys: up down left right select back playpause hold relaunch none text:<word>
# ("hold" is a long press of OK, which opens a surah's or reciter's menu.)
#
# Sidebar order: Home, Search, Surahs, Reciters, Adhkar, Library, Settings,
# then the now-playing tile under Settings while something is queued. Up is
# trapped at Home and Down at the tile, so "up x7 down xN" from any place
# item lands on place N (Home is 0), and from the tile "up x8" reaches Home.
#
# Back on a root place is stepwise: from the content it focuses that place's
# own sidebar item; from the sidebar of any other place it goes Home; on
# Home's sidebar it leaves the app. So every section starts from a known
# focus with exactly one Back from the content ("back up x7 down xN select"),
# or with no Back at all when focus is already on the sidebar. The walk never
# presses Back on the sidebar: where focus lands after the switch to Home is
# not something to build on, and on Home's sidebar it would exit.
# Run DRY_RUN=1 bash e2e/run-walk.sh android to check this file.
